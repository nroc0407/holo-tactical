# Demo models

Six models from the Theseus project, used by `demo/trial.tscn` to show the hologram tracing real
game models. Self-contained glTF binaries (`.glb`), flat colours, no external textures, metres,
+X forward, +Y up.

| File | What | Size |
|---|---|---|
| `torpedo_boat.glb` | Torpedo boat | 28 m long |
| `patrol_boat.glb` | Patrol boat | 44 m long |
| `missile_boat.glb` | Missile boat | 39 m long |
| `bomber_small.glb` | Small bomber | about 15 m span |
| `torpedo_small.glb` | Small torpedo bomber | about 15 m span |
| `rocket_fighter.glb` | Rocket fighter | about 12 m span |
