# Changelog

## 0.1.0

- First release, extracted from the Theseus naval game.
- Engine-neutral spec (English and Korean), palette and symbol data.
- Godot 4.7 addon: feed interface, full-screen hologram, miniature table, wireframe tracer, contours, glow, headless line dump.
- Demo with a made-up battle (primitive models) and a trial scene with six game models.
- Python reference: feature edges, contours, line-dump renderer.
